Deux réalisations graphiques, mises en page directement en HTML et CSS plutôt que dans un
logiciel de design — c'était l'exercice.

## Contenu

| Dossier | Ce que c'est |
| --- | --- |
| `nexaweb-card/` | Carte de visite reprenant l'identité du site [NexaWeb](https://github.com/Pierre-Dunand-Chatellet/NexaWeb) : recto et verso |
| `octobre-rose/` | Affiche faite à la demande d'un ami pour Octobre Rose (2025) |

En ligne :

- https://dunandchatellet.fr/design/nexaweb-card/carte.html
- https://dunandchatellet.fr/design/octobre-rose/octobre-rose.html

## Comment c'est fait

Une page HTML et une feuille de style par pièce, aux dimensions d'impression. Les visuels
définitifs sont dans les dossiers `Image/`.
